## Ini adalah project 2 CCIT Semester 3 Quarter 1.

**Judul** : Capsule Letter

**Bahasa** : PHP Native

**Deskripsi** : Sebuah website dengan PHP Native. Pada website dapat menulis *harapan, keinginan, dan yang lainnya untuk masa depan*. Ketika surat itu dibuka di masa depan maka kamu akan mendapatkan refleksi diri dengan apa yang telah kamu lakukan selama ini dan apakah kamu berhasil menggapai atau memenuhi apa yang kamu tulis di surat.
